# zeotein-theme

Zeotein web builds that live outside the Shopify admin.

| Folder | What it is |
|---|---|
| [`mix-hero/`](mix-hero/) | Animated "build the shake" hero for Zeotein Cacao, plus the 1080x1920 laptop reel rendered from it (`mix-hero/out/zeotein-mix-reel.mp4`). |
| [`google-site/`](google-site/) | The Google-only Zeotein website for GoHighLevel ("Zeotein Google Site"): eight paste-ready page blocks, the build script, and the compliance and render checks. Start with [`google-site/README.md`](google-site/README.md) or open `google-site/dist/install-kit.html`. |
