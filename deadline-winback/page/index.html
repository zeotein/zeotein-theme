Proof: the code stops working at the deadline

Same cart both times: Vegan 7 Stick Packs ($44.99) plus the $76.99 Starter Kit first order. The test codes have the exact shape Deadline Funnel will create: $44.99 off the Vegan 7-Day only, one use, one per customer, with an end time.

Partly verified

What this proves: Shopify itself enforces the end time on a per-person code. That is the mechanism Deadline Funnel uses, so a code it issues will fail at checkout once that person's 5 days are up.

What it does not prove yet: that Deadline Funnel creates the code with these settings, starts the clock from the GoHighLevel webhook, and shows the timer. That end-to-end run with Dana's test contact is step 5 of the build below. The storefront checkout could not be screenshotted from the cloud workspace either: Shopify's bot check answered "Your connection needs to be verified". The Lenovo session takes those screenshots.

How the free 7-Day gets into the order

Chosen

The code itself makes the Vegan 7-Day free, visible at checkout

Deadline Funnel makes amount codes and can limit them to one product. A $44.99 code limited to the Vegan 7 Stick Packs turns that bag into $0.00 in the cart, so the customer sees the gift before paying. No Shopify Flow is needed to add the gift line, which removes the step where a Flow could fail or double up. The live Vegan 7-Day product is Active, so Deadline Funnel can select it (it cannot see unlisted products like sbf-gift-7day-vegan).

After the deadline the same cart charges $44.99 for that bag, so the page and checkout fall back to the regular $76.99 offer with no gift.

Found in testing

A minimum spend cannot force the Starter Kit into the cart

The first test code had a $121.98 minimum. Shopify refused it with the kit in the cart, because on a product-limited code Shopify counts only the gift product toward the minimum. So the code alone cannot require a Starter Kit.

The guard instead: one small Shopify Flow. When an order is paid with a WBGIFT code and no Starter Kit line, it tags the order wb-gift-no-kit and emails Dana. It never cancels anything. Worst case is one free Vegan 7-Day per person, once, because each code is single-use.

Three things the build has to respect

Timing

WB9003 lands after the deadline. The win-back sends on Day 0, Day 3 and Day 6. A 5-day clock from the first email ends before Day 6. Recommended: the gift version sends Day 0, Day 2 and Day 4, so the last reminder arrives with about a day left.

The Sale hold pauses emails, not the clock. Between 20 Nov and 1 Dec the Sale active gate holds win-back emails, and win-back never mixes with Black Friday. Recommended: switch the gift on after 1 Dec, so nobody's 5 days run out while their reminders are held.

People already in the flow

203 lapsed buyers got WB9001 on 16 Nov, before any webhook existed, so they have no clock and no code. Recommended: they finish on the current templates with the regular offer and no gift. The gift lives in three new templates on a new branch for new entrants, so no countdown image ever shows to someone without a deadline.

Stacking

The live Shopify Flow that gives a first-order-back free 7-Day must skip orders carrying a WBGIFT code, so nobody gets two free bags. That Flow cannot be read through the API; the Lenovo session checks it in the Flow editor.
