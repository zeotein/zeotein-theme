Faster: let Claude on your PC do the install

This kit was built in a cloud session, which can't reach your browser. On your PC, open the Claude desktop app, start a session that runs on your computer with Claude in Chrome connected, and paste this prompt. Or do the steps below yourself.

    • Sites → Websites → Zeotein Google Site. You should see Home, Cacao, Vegan, Our story, FAQ, Contact, Shipping and Refund policy.
    • Open the page in the builder. Remove the draft sections that are there now (clone the page first if you want a copy).
    • Add one full-width section with one row and one column. Set section, row and column padding to 0 and background to none.
    • Add a Custom JS/HTML element (newer builders call it Code). Paste that page's block from Page blocks. Save.
    • Page settings → SEO meta data: paste the page's title and description. Save.
    • Website settings → Tracking code already holds the Google Ads tag AW-18130788543, the Meta pixel, Clarity and the gclid/UTM passthrough. The page blocks do not repeat any of them, and they add one thing it lacks: ad parameters now follow a visitor from page to page.
    • Use the builder's preview link. Every buy button should open a zeotein.com product page: Cacao Starter Kit at $76.99, Vegan Starter Kit at $96.99.
    • Approved: shop.zeotein.com.
    • Settings → Domains → Add domain → add the DNS record GoHighLevel shows at the zeotein.com DNS host → Verify → make Zeotein Google Site the domain's default website so the bare domain opens Home.
    • Ask Claude to run the compliance prescan on every live URL, as the Guardrails require before any campaign moves.
    • Click test: open https://shop.zeotein.com/cacao?gclid=TEST&utm_source=google, tap Claim My 55% Off, and confirm the Shopify page shows $76.99 with gclid=TEST in the address bar.
    • See Google Ads for the final URLs and sitelinks. Then update the Ad Setup Guardrails destination list (Dana edits that doc).

Two layers, run on every built page

Compliance

Layer 1 is your zeotein-compliance-scrub prescan (Google healthcare, FDA/DSHEA, FTC patterns) run on page text, alt text, attributes and schema. Layer 2 is your house rules from the Guardrails, the Headlines Test Queue, the Ad Comment Replies rules and the Decisions log.
