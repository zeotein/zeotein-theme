Faster: let Claude on your PC do the install

This kit was built in a cloud session, which can't reach your browser. On your PC, open the Claude desktop app, start a session that runs on your computer with Claude in Chrome connected, and paste this prompt. Or do the steps below yourself.

    • See Approval. Yes: use the standard Home, Cacao and Vegan blocks. No: use their no-rating versions. Every other page is the same either way.
    • Sites → Websites → Zeotein Google Site → add a page for each, with these exact paths: /single-ingredients, /collagen, /bone-broth, /hemp-protein, /pumpkin-seed-protein, /cacao-powder, /mct-oil-powder, /sea-moss, /lions-mane. The blocks link to these paths, so a different path breaks the links.
    • Open the page in the builder and remove the sections that are there now (clone the page first if you want a copy).
    • Add one full-width section with one row and one column. Set section, row and column padding to 0 and background to none.
    • Add a Custom JS/HTML element (newer builders call it Code). Paste that page's block from Page blocks. Save.
    • Page settings → SEO meta data: paste the page's title and description. Save.
    • Website settings → Tracking code → Head. Keep the Google Ads tag AW-18130788543, the Meta pixel and Clarity. Replace the old Zeotein snippet with this one and save. Leave the Body tracking code as it is.
    • It starts with <meta name="robots" content="noindex, follow">, so the shop stays out of Google Search while ads still run. A noindex line you added by hand can stay (a duplicate is harmless) or go.
    • On a phone and a desktop: Cacao → Starter Kit, Every 6 weeks → Add to cart; then Single Ingredients → Sea Moss 1/2 lb → Add to cart. The cart should show $76.99 (then $99.99 per delivery) and $59.99, subtotal $136.98.
    • Press Checkout. Shopify checkout should list both items and say "First payment $76.99, then $99.99 every 6 weeks". Stop there: no details, no payment.
    • Claude runs qa/e2e_cart.js, qa/link_check.py and the compliance prescan against https://shop.zeotein.com and reports back.
    • No final URL moves to shop.zeotein.com until the hold lifts. The table in Google Ads is ready for that day.
